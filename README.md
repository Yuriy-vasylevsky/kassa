# Telegram-бот «Каса» на Python

Приватний Telegram-бот для ведення й розрахунку каси. Працює на вашому комп’ютері через long polling. Google Sheets, Google Apps Script, webhook і публічний сервер не потрібні. Таблиця була лише прикладом полів та формул.

Каса й стан редагування зберігаються у **SQLite** (`data/kassa.sqlite3`) та залишаються після перезапуску. Усі суми обчислюються цілими копійками.

## Локальний запуск у Windows / VS Code

Потрібен Python **3.10+** та інтернет. Відкрийте PowerShell у папці проєкту:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

У `.env` замініть `put_your_bot_token_here` на токен від **@BotFather**. Ваш ID уже вказано:

```dotenv
TELEGRAM_TOKEN=put_your_bot_token_here
ALLOWED_USERS=752963390
DATABASE_PATH=data/kassa.sqlite3
REPORT_HIDE_ZERO_BALANCES=true
```

Запустіть:

```powershell
.\.venv\Scripts\python.exe main.py
```

Відкрийте свого бота в Telegram і надішліть **/start**. Зупинка — **Ctrl+C**. Активація середовища не потрібна, тому політика виконання PowerShell не заважає запуску.

Якщо `python` відкриває Microsoft Store, використайте `py` або встановлену команду `python3.14` замість `python` у першій команді. Якщо є `uv`, середовище та залежності можна підготувати так:

```powershell
uv venv .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
```

Повторний запуск потребує лише команди `main.py`; не копіюйте `.env.example` поверх налаштованого `.env`. Змінні середовища мають пріоритет над `.env`. Відносний шлях бази рахується від папки проєкту.

## Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
# Впишіть токен у .env
.venv/bin/python main.py
```

## Робота з касою

- У готовому звіті всі рядки з нульовими сумами приховані, незалежно від старого налаштування `REPORT_HIDE_ZERO_BALANCES`. Повністю нульові ігрові блоки пропускаються разом із заголовком. Від’ємні суми залишаються. Раніше збережені звіти залишаються знімками на момент створення; щоб оновити сьогоднішній, сформуйте його знову.

- Команди, введені значення та повідомлення від нижніх кнопок автоматично видаляються після обробки. Тимчасова підказка нижньої клавіатури також видаляється. Каса або історія переноситься в кінець чату після нового повідомлення чи відкриття звіту; попередній блок видаляється після успішного надсилання нового. Кнопки всередині блоку оновлюють його на місці.

- Унизу головного меню є **📚 Історія звітів**. Кнопки дат (наприклад, **жовтень 2**) відкривають останній сформований звіт за відповідний день; на сторінці до 7 дат, від нових до старих.
- **Готовий звіт** і `/report` зберігають звіт в історії. Повторне формування за той самий день замінює попередній знімок. Перегляд історії та видалення повідомлення зі звітом не змінюють збережені звіти.
- Угорі каси та історії показано **Чистий дохід за місяць** — суму чистих доходів останніх звітів за всі збережені дні, включно з від’ємними значеннями. Незбережені зміни поточної каси до неї не входять.
- Історія спільна для дозволених користувачів, переживає перезапуск і **Нову касу**. Зберігається лише поточний місяць за київським часом: при першій взаємодії в новому місяці попередні звіти автоматично видаляються. Старі повідомлення в Telegram не імпортуються.

- На головному екрані видно короткі підсумки. Відкрийте розділ **Старт**, **Ігри**, **Витрати** або **Залишки**, натисніть поле й надішліть число — бот оновить те саме повідомлення каси.
- Число **замінює** значення поля. Підтримуються мінус, пробіли, кома та крапка: `-5 000,50`. До двох знаків після коми; межа — ±10 млрд грн на поле й розрахований підсумок.
- **Готовий звіт** або `/report` надсилає звичайний текст. Для звітів до 256 символів є кнопка **📋 Скопіювати**. Довші звіти копіюйте повністю через меню повідомлення: на ПК натисніть правою кнопкою на текст → **Копіювати текст**; на телефоні затисніть повідомлення → **Копіювати**. Кнопка **📋 Як скопіювати весь звіт** показує цю підказку. Після копіювання натисніть **✅ Скопійовано — видалити**, щоб прибрати повідомлення зі звітом; дані каси зберігаються. Ця кнопка тільки видаляє повідомлення, а не копіює його. Telegram не повідомляє бота про копіювання, тому видалення потребує окремого натискання.
- Поля **Мої 1**, **Мої 2**, **Борг** і **Баланс гравців** враховуються в сумі **На карті**, але окремими рядками до готового звіту не додаються.
- **НОВА КАСА** після підтвердження переносить поточну суму **На карті** в поле **Отримав**, яке формує **Старт** нової каси. Решта полів очищається; історія звітів зберігається. Підтвердження діє 2 хвилини.
- `/cancel` скасовує редагування чи підтвердження очищення; `/start` оновлює касу; `/help` показує підказку.

Доступ мають лише ID з `ALLOWED_USERS`, виключно в особистому чаті. Щоб додати користувача, впишіть його ID через кому й перезапустіть бота. Усі дозволені користувачі працюють з **однією спільною касою**, кожен має власне повідомлення. Після чужих змін `/start` оновлює показники. Очищення скасовує незавершене редагування всіх користувачів.

## Формули

- Старт = Отримав + ЗП + ІНК + Приход.
- Дохід джерела = ВХ − ВИХ; загальний дохід = Чемпіон + Супероматік + Грін.
- Теоретичний баланс = Старт + загальний дохід.
- На карті = сума банків, обох «Мої», боргу й балансу гравців зі знаками.
- Фактичний розхід = теоретичний баланс − на карті.
- Чистий дохід = загальний дохід − фактичний розхід.
- Різниця витрат = фактичний розхід − сума внесених категорій витрат.

Контрольний приклад: старт **11459**, дохід **5022**, теоретичний баланс **16481**, на карті **15831**, розхід **650**, чистий дохід **4372**, різниця **0**.

## Збереження та налаштування

| Змінна | Призначення |
| --- | --- |
| `TELEGRAM_TOKEN` | Токен бота від @BotFather |
| `ALLOWED_USERS` | Дозволені Telegram ID через кому; обов’язково |
| `DATABASE_PATH` | Файл SQLite, типово `data/kassa.sqlite3` |
| `REPORT_HIDE_ZERO_BALANCES` | `true` приховує нульові залишки у звіті; `false` показує їх |

`.env`, локальні дані та база виключені з Git. Для резервної копії зупиніть бота й скопіюйте файл бази. Історія днів автоматично не архівується: перед очищенням збережіть готовий звіт. Новий бот починає з нульової каси; дані старого Apps Script автоматично не імпортуються.

Бот відповідає, поки запущена програма та комп’ютер має інтернет. Для безперервної роботи запустіть ту саму програму на постійно увімкненому комп’ютері або сервері. Запускайте лише один екземпляр на один токен. Під час запуску бот видаляє попередній webhook, щоб перейти на polling.

Нові поля та джерела доходу додаються у `kassa/cash.py`. Кнопки, категорії та звіт будуються з цих налаштувань.

## Перевірка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тести не звертаються до Telegram: перевіряють формули, копійки, доступ, збереження, атомарність запису, повторні повідомлення, кнопки, звіт і очищення.

Використовується [python-telegram-bot 22.7](https://docs.python-telegram-bot.org/en/v22.7/telegram.ext.application.html).
